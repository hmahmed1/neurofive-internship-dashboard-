# 🎓 Internship Dashboard — Neurofive Week 1

A searchable, filterable internship listing dashboard built with **Vite + React 18 + TypeScript**. Consumes a local mock JSON dataset via `fetch`, includes a details view, and an apply form with client-side validation.

---

## 🚀 Setup Instructions

### Prerequisites
- Node.js 18+ installed ([download](https://nodejs.org))
- npm (comes with Node.js)

### Install & Run

```bash
# 1. Clone the repository
git clone <your-repo-url>
cd my-first-app

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
